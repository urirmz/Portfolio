Core Content

Weeks 1–7 · ~49 hrs
W1
Domain 1 IAM & Security Foundations 6–8 hrs
⚠️Domain 1 is 30% of the exam — the highest weight. Do not rush through this.
  • IAM: users, groups, roles, policies, permission boundaries
  • Service Control Policies (SCP) and AWS Organizations
  • KMS key types, key policies, encryption in transit vs at rest
  • CloudHSM, ACM (Certificate Manager), Secrets Manager vs Parameter Store
  • S3 security: bucket policies, ACLs, Block Public Access, Object Ownership
Maarek § IAM Maarek § KMS Maarek § S3 Security
W2
Domain 1 Networking & Edge Security 6–8 hrs
⚠️Known weak spot for backend engineers. Invest extra time here — VPC questions appear in every domain.
  • VPC deep-dive: subnets (public/private), route tables, IGW, NAT Gateway vs NAT Instance
  • Security Groups (stateful) vs NACLs (stateless) — know the difference cold
  • VPC Peering, Transit Gateway, VPC Endpoints (Gateway vs Interface)
  • Site-to-Site VPN, Client VPN, AWS Direct Connect (Dedicated vs Hosted)
  • CloudFront, WAF, Shield (Standard vs Advanced), Global Accelerator
Maarek § VPC Maarek § CloudFront AWS VPC FAQ
W3
Domain 2 Compute & High Availability 6–8 hrs
  • EC2 instance types, placement groups (Cluster, Spread, Partition)
  • Launch Templates, Auto Scaling Groups — scaling policies & lifecycle hooks
  • ELB types: ALB (Layer 7), NLB (Layer 4), GWLB — when to use each
  • Lambda: invocation models (sync, async, event source mapping), concurrency limits
  • API Gateway: REST vs HTTP vs WebSocket, throttling, caching, deployment stages
Maarek § EC2 Maarek § ELB & ASG Maarek § Lambda
W4
Domain 2 Storage, Databases & Disaster Recovery 6–8 hrs
  • S3: versioning, replication (CRR/SRR), lifecycle policies, S3 Transfer Acceleration
  • EBS volume types (gp3 vs io2 vs st1 vs sc1), snapshots, EFS vs FSx
  • RDS: Multi-AZ (synchronous standby) vs Read Replicas (async) — understand the distinction
  • Aurora: cluster architecture, Global Database, Serverless v2, backtrack
  • DynamoDB: partition keys, GSI/LSI, DAX, streams, global tables, on-demand vs provisioned
  • DR strategies: Backup & Restore → Pilot Light → Warm Standby → Active-Active
Maarek § RDS / Aurora Maarek § DynamoDB Maarek § S3
W5
Domain 3 Decoupling, Messaging & Streaming 6–8 hrs
  • SQS: standard vs FIFO, visibility timeout, DLQ, long polling — Java SDK patterns
  • SNS: fan-out pattern, message filtering, FIFO SNS + SQS combo
  • EventBridge: event bus, rules, targets, schema registry
  • Kinesis: Data Streams (shards/consumers) vs Firehose (delivery) vs Analytics
  • Step Functions: Standard vs Express workflows, error handling, parallel states
Maarek § SQS / SNS Maarek § Kinesis Maarek § Step Functions
W6
Domain 3 Containers, Caching & Analytics 6–8 hrs
  • ECS (EC2 vs Fargate launch types), EKS (managed node groups), task definitions
  • ElastiCache: Redis (persistence, pub/sub, sorted sets) vs Memcached (simple caching, multithreaded)
  • CloudFront caching: cache behaviors, TTL, cache invalidation, signed URLs vs signed cookies
  • Redshift (columnar OLAP), Athena (serverless SQL on S3), Glue (ETL), OpenSearch
  • App Runner, Elastic Beanstalk — when to recommend managed compute vs DIY
Maarek § ECS / EKS Maarek § ElastiCache Maarek § Analytics
W7
Domain 4 Cost Optimization 6–8 hrs
⚠️Another known weak spot for devs. Cost reasoning is pure architect thinking — master the trade-offs.
  • EC2 pricing: On-Demand, Standard Reserved, Convertible Reserved, Savings Plans, Spot (interruptions!), Dedicated Hosts vs Instances
  • S3 storage classes: Standard → IA → Glacier Instant → Glacier Flexible → Deep Archive — know retrieval times
  • S3 lifecycle policies: transition rules, expiration rules, minimum storage durations
  • Cost Explorer, AWS Budgets, Cost Anomaly Detection, Trusted Advisor cost checks
  • Right-sizing, serverless cost patterns (pay-per-invocation vs always-on)

Architecture Thinking

Week 8 · ~7 hrs
W8
Patterns Well-Architected Framework & Design Patterns 6–8 hrs
  • AWS Well-Architected Framework: 6 pillars (Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, Sustainability)
  • Serverless architecture patterns: Lambda + API GW + DynamoDB, event-driven fan-out
  • Microservices on AWS: ECS/EKS + ALB + SQS, service mesh with App Mesh
  • Migration strategies — the 7 Rs: Retire, Retain, Rehost, Replatform, Repurchase, Refactor, Relocate
  • CloudFormation & CDK: stacks, nested stacks, change sets, drift detection
  • Scenario drills: given a requirement → select the right AWS services + justify the trade-offs

Exam Strategy

  • Eliminate obviously wrong answers first — usually 2 options are clearly off
  • When in doubt, AWS favors managed services over self-managed
  • For cost questions, Spot > Reserved > On-Demand for savings
  • Flag difficult questions and return — don't get stuck
  • Read questions to the end — the constraint is usually in the last sentence

Weekly Rhythm

  • Split into 3 sessions of ~2 hrs each, not one 7-hr marathon
  • Watch video → take notes → do 10–15 practice questions on that topic
  • Keep a running "mistake log" of wrong practice answers
  • After Week 7, stop watching new videos — only review and practice
  • Don't book the exam until scoring 80%+ on 2 consecutive full mocks
